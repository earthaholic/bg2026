  2. 2
    수업을 마쳤다면 학습 이력 일괄 등록을 누릅니다.

로그인하기

  1. 안내받은 bg2026 업무 사이트를 엽니다.
  2. 발급받은 아이디와 비밀번호를 입력하고 로그인을 누릅니다.
  3. 상단에 표시된 사용자와 역할을 확인합니다. 일반 선생님의 역할 표시는 선생님입니다.
  4. 왼쪽 메뉴에서 필요한 업무를 선택합니다. 공용 컴퓨터에서는 업무를 마친 뒤 로그아웃합니다.

비밀번호를 잊었거나 계정이 없으면 관리자에게 계정 발급 또는 비밀번호 초기화를 요청하세요. 비밀번호를 메시지나 화면 사진에 포함해 보내지 마세요.

화면 읽는 법

  • 왼쪽 메뉴: 업무 화면을 바꿉니다. 메뉴명과 버튼명은 실제 화면에 적힌 대로 굵게 표시했습니다.
  • 검색 조건: 검색어·날짜·필터를 조합해 목록을 좁힙니다. 원하는 결과가 없으면 조건을 먼저 풀어보세요.
  • 목록과 상세: 목록에서 이름이나 상세 버튼을 누르면 자세한 정보가 나옵니다. 여러 페이지가 있으면 이전·다음으로 이동합니다.
  • 저장 안내: 저장 후 완료 또는 오류 메시지를 확인합니다. 화면에 입력한 것만으로는 저장되지 않습니다.

직접 할 수 있는 일과 요청할 일

직접 처리하는 일관리 선생님·관리자에게 요청하세요
본인 담당 수업·학생 조회, 도서 검색새 수업·학생 등록, 학생의 반 배정 변경
담당 수업의 학습 기록 등록, 본인 진행 기록의 허용된 정정기록의 학생·연결 수업·실제 진행 선생님 변경
학생 특이사항 전용 수정, 빈 수업 내용 보완학생 기본정보 전체 수정, 미입력 실제 진행 선생님 지정
월말보고 작성·저장·복사, 도서·자료 등록 요청도서 직접 등록·수정, 요청 승인·반려
본인 월급 정산 조회, 본인 추가 청구정산 단가 설정, 정산 제외·복원, 정산 마감

내 수업과 학생 확인하기

  1. 수업 목록 & 상세에서 수업을 찾습니다. 일반 선생님에게는 본인 담당 수업이 표시됩니다.
  2. 수업 상세에서 수업명·담당 선생님·요일·시간·수강 학생을 확인합니다.
  3. 학생 구성이 실제와 다르면 관리 선생님에게 확인을 요청합니다. 명단에 없는 학생을 다른 학생 대신 선택하지 마세요.

학생 특이사항 확인·수정하기

  1. 학생 검색 & 상세 조회에서 학생을 검색하고 학생 이름을 눌러 상세를 엽니다.
  2. 특이사항을 읽습니다. 고칠 내용이 있으면 특이사항 수정을 누릅니다.
  3. 내용을 입력한 뒤 특이사항 저장을 누르고 저장된 내용을 확인합니다.

여기서는 특이사항만 수정할 수 있습니다. 이름·학년 등 기본정보 전체 수정은 관리 선생님에게 요청하세요. 다른 사람이 먼저 특이사항을 바꿨다는 안내가 나오면, 작성한 내용을 따로 보관한 뒤 최신 내용을 확인하여 다시 정리합니다.

특이사항에는 교육에 필요한 내용만 적으세요.관찰한 내용과 전달 사항을 적되, 불필요한 개인정보나 확인되지 않은 판단은 넣지 않습니다.

수업에 사용할 도서 찾기

  1. 도서 검색 & 상세 조회에서 제목·저자·출판사·주제 등의 검색어를 입력하고 검색을 누릅니다.
  2. 필요하면 상세 필터에서 난이도, 분량·어휘 단계, 보유 자료 조건을 좁힙니다.
  3. 미학습 학생 조건을 사용하면 선택한 학생 모두가 아직 학습하지 않은 도서를 찾을 수 있습니다.
  4. 도서 상세에서 제목·저자·출판사와 자료 보유 상태를 확인합니다.

PDF 상태는 미보유, PDF 보유(저작권 있음), PDF 보유(저작권 없음)으로 구분됩니다. 자료를 보유하고 있다고 해서 이용·배포가 허용되는 것은 아닙니다. 실제 사용할 때는 운영 기준과 저작권을 확인하세요.

시작 전 확인

담당 수업에 학생이 올바르게 배정되어 있어야 합니다. 실제 수업일, 사용한 도서, 참석·결석 명단, 특강 여부를 준비하세요.

  1. 일괄 등록할 수업 선택에서 본인 수업을 고릅니다. 표시된 수업 정보와 수강 학생을 확인합니다.
  2. 예정 도서 목록이나 도서 검색에서 실제 사용한 도서를 선택합니다. 여러 권을 사용했다면 선택한 도서 목록을 모두 확인합니다.
  3. 학습 일자를 실제 수업일로 맞춥니다. 달력에 표시된 기존 이력과 휴강 일정도 확인합니다.
  4. 수업 내용에 진행한 활동을 입력합니다. 이 내용은 참석 학생 모두의 기록에 저장됩니다. 학생별 메모는 학생 목록의 메모 열에서 추가를 눌러 적습니다. 개인별 민감한 내용을 공통 수업 내용에 넣지 않습니다.
  5. 학생별 참석과 특강을 확인합니다. 반 설정에 따라 특강에 미리 체크되어 있을 수 있습니다. 당일 수업과 맞는지 확인하세요.
  6. 결석 학생은 참석 체크를 해제하고 필요하면 결석 사유를 입력합니다. 전원 결석일 때에는 도서를 선택하지 않아도 됩니다.
  7. 선택 학생 학습 기록 일괄 등록을 누릅니다. 완료 안내가 나오면 참석 기록은 학습 기록 검색에서, 결석은 월말보고의 결석 내역에서 확인합니다.

    작성자와 수정 시각, 저장 완료 표시가 나오면 문서가 저장된 것입니다. 문자 발송이 끝났다는 뜻은 아닙니다.

새 보고서 작성하기

  1. 학생 선택에서 담당 학생을 고릅니다. 이름을 찾기 어려우면 옆의 검색을 이용합니다. 저장한 보고가 없는 학생이 먼저, 이후에는 마지막 저장이 오래된 학생 순으로 표시됩니다.
  2. 전체 기록 불러오기를 누릅니다. 필요한 학습 시작일·학습 종료일을 지정하고 기간 적용으로 보고할 범위를 맞춥니다.
  3. 저장할 보고 월을 지정합니다. 학기/기간 문구, 문장에 쓸 보고 월, 필요 시 특강 담당 선생님 이름을 확인합니다.
  4. 포함할 학습 기록과 결석 내역을 체크합니다. 전체 선택·전체 해제를 사용해도 최종 대상은 한 번 더 확인합니다.
  5. 시작 강의 번호를 확인합니다. 선택한 학생과 기록의 결제 이력에 맞춰 자동 계산 안내가 나옵니다. 실제 운영 기준과 맞는지 확인하세요.
  6. 문자 양식 미리보기에서 이름·기간·날짜·도서·강의 번호·특강·결석을 점검합니다. 필요한 문구는 미리보기에서 직접 수정합니다.
  7. 작성 중이면 임시 저장, 최종 확인을 마쳤으면 저장 완료를 누릅니다. 저장 상태 안내를 확인합니다.
  8. 클립보드에 복사를 누른 뒤 실제 발송에 사용하는 문자·메신저에 붙여넣습니다. 수신자와 붙여넣은 내용을 다시 확인한 후 해당 도구에서 발송합니다.
저장할 월과 기록 기간을 각각 확인하세요.저장할 보고 월은 문서를 보관하는 기준, 보고 월은 문장에 표시할 표현, 학습 시작일·종료일은 포함할 기록의 범위입니다. 보고 월 글자만 바꾸고 기록 기간도 바뀌었다고 생각하지 마세요.

저장한 보고서 이어서 작성하기

  1. 학생을 선택하고 이전 기록 불러오기에서 저장 문서를 고릅니다. 필요하면 옆의 새로고침 버튼으로 저장 목록을 갱신합니다.
  2. 불러온 보고 월, 선택 기록, 미리보기 문구를 확인하고 수정합니다.
  3. 임시 저장 또는 저장 완료를 누릅니다. 같은 학생·같은 보고 월로 저장하면 기존 문서를 갱신합니다.

결석과 여러 도서는 어떻게 표시되나요?

  • 결석은 날짜순으로 수업 불참 안내에 포함되며 강의 번호를 소진하지 않습니다. 과거에 결석을 저장하지 않았다면 자동으로 복원되지 않습니다.
  • 같은 학생·날짜·실제 진행 선생님·수업·일반/특강·수업 내용의 여러 도서는 한 차시로 묶고 도서명은 모두 표시합니다.
보고서 작성 중 수업 구분 변경은 원본도 바꿉니다.선택 목록에서 일반/특강을 변경하면 허용된 경우 원본 학습 기록에 즉시 저장됩니다. 문구만 바꾸는 기능이 아닙니다. 본인 기록의 수정 권한과 정산 마감 여부에 따라 변경이 제한됩니다. 기존에 저장한 월말보고 문구는 원본을 나중에 수정해도 자동 변경되지 않으므로 별도로 확인·수정·저장하세요.

미리보기를 직접 다듬은 뒤 학생·기록·설정을 다시 바꾸면 생성 문구가 달라질 수 있습니다. 최종 문구를 다시 읽고 저장하세요. 저장 완료는 문서 저장 상태이며 실제 문자 발송 완료를 뜻하지 않습니다.

시작 전 확인

도서 검색에서 동일 도서가 이미 있는지 확인하세요. 기존 도서에 자료만 추가하려면 도서 상세에서 대상 도서 번호를 확인해 둡니다.

  1. 요청 유형에서 기존 도서 자료 추가 또는 새 도서 등록을 고릅니다.
  2. 도서 분류를 그림책 또는 일반 도서로 선택합니다.
  3. 기존 도서라면 대상 도서 번호를 입력합니다. 새 도서라면 도서명·저자·출판사 등 화면의 필수 항목과 확인 가능한 정보를 작성합니다.
  4. 퀴즈·독서 문제·독서 답안·글쓰기 문제·글쓰기 답안·심화 자료·토론 자료 중 실제 요청할 자료를 선택합니다. PDF는 추가 여부와 저작권 상태를 구분합니다.
  5. 도서와 자료 선택을 검토한 뒤 승인 요청 등록을 누릅니다.
  6. 내 요청 내역에서 요청이 등록되었는지, 대기·승인·반려 중 어느 상태인지 확인합니다.

요청 후 알아두기

  • 승인 전에는 도서 정보에 반영되지 않습니다. 필요한 수업 전에 처리 상태를 확인하세요.
  • 반려되면 표시된 처리 내용을 확인하고 필요한 정보를 보완해 다시 요청합니다. 본인의 대기·반려 요청은 삭제할 수 있지만 승인된 요청은 삭제할 수 없습니다.
  • 승인된 자료 요청은 승인 시 적용되는 자료 제작 단가로 해당 정산월에 반영됩니다. 자료 종류를 선택하지 않고 새 도서만 등록했다면 자료 제작비 정산 대상이 아닙니다.
  • 선택한 보유 정보와 실제 자료 상태가 맞는지 확인하세요. 요청을 등록했다고 파일 업로드·전달이나 사용 허가까지 끝난 것은 아닙니다.

  1. 정산월을 고르고 정산 조회를 누릅니다. 일반 선생님에게는 본인의 내역이 표시됩니다.

정산 내용을 읽을 때

  • 복수 도서가 같은 차시 기준에 해당하면 수업 수당은 한 번 계산합니다. 도서별 기록 수와 정산 차시는 같지 않을 수 있습니다.
  • 수업 당시 종류·단가를 보존한 기록은 이후 반 설정이나 단가 변경을 그대로 따라가지 않습니다. 도입 시점 기준 보존은 기능 도입 때의 계산 기준을 보존한 것이며 과거 단가를 복원했다는 뜻이 아닙니다.
  • 단가를 설정하지 않은 내역과 단가가 0원인 내역은 다릅니다. 정산 기준이 없다는 안내가 보이면 임의로 학습 기록을 바꾸지 말고 확인을 요청합니다.
  • 상담은 기록된 상담일과 담당자를 기준으로 건당 계산하며 소요 시간에 비례하지 않습니다. 상담 정보 보완과 정산 제외·복원은 관리 선생님에게 요청합니다.
  • 정산에서 제외되어도 원본 학습 기록이나 상담 내용이 삭제된 것은 아닙니다. 일반 선생님은 제외·복원이나 마감을 직접 하지 않습니다.

  2. 청구일·항목명·금액·사유를 작성합니다.
  3. 실제 청구 근거와 금액을 확인한 뒤 청구 등록을 누릅니다.
  4. 추가 청구 목록과 정산 합계에 반영되었는지 확인합니다. 정정이 필요하면 본인의 미마감 청구에 제공되는 수정·삭제 기능을 이용합니다.

10 · 문제가 생겼을 때

바로가기

오류 문구를 읽고 아래에서 해당하는 상황을 찾아보세요. 해결되지 않으면 이 장 끝의 양식으로 관리 선생님에게 문의하세요.

1

삭제창을 잘못 열었다면 취소합니다

  1. 1
    이 칸은 정말 삭제할 때만 확인 문구를 적는 곳입니다. 단순히 내용을 고치려던 것이라면 입력하지 마세요.
  2. 2
    취소를 눌러 돌아갑니다. 기록을 삭제하면 화면에서 복구할 수 없습니다.
내 수업이나 학생이 보이지 않아요.

상단 로그인 계정이 본인인지 확인합니다. 검색어·필터를 해제하고 다시 조회합니다. 일반 선생님에게는 본인 담당 수업과 배정 학생을 중심으로 표시됩니다. 새 학생 등록이나 반 이동, 담당 변경이 아직 반영되지 않았을 수 있습니다. 학생 이름과 수업명을 관리 선생님에게 전달해 배정을 확인받으세요.

저장 버튼을 눌렀는데 응답이 없거나 오류가 났어요.

버튼을 반복해서 누르지 마세요. 오류 문구를 확인하고, 입력 내용은 안전한 곳에 잠시 보관합니다. 목록이나 저장 이력을 다시 조회해 이미 처리되었는지 확인한 뒤 다시 시도합니다. 로그인 만료라면 재로그인 후 상태를 확인합니다. 화면만 새로고침하면 미저장 내용이 사라질 수 있습니다.

학습 기록의 수정·삭제 버튼이 없어요.

본인 진행 기록인지, 실제 진행 선생님 또는 연결 수업의 담당자 정보가 있는지, 정산이 마감되었는지 확인합니다. 등록자나 현재 반 담당자라는 이유만으로 수정할 수 있는 것은 아닙니다. 상세창의 제한 안내와 기록 번호를 관리 선생님에게 전달하세요.

중복 기록 또는 휴강·결석 충돌 안내가 나와요.

같은 학생·날짜·도서의 기존 학습 기록을 검색하고 해당 수업의 결석·휴강도 확인합니다. 오류를 피하려고 날짜나 학생을 다른 값으로 바꾸지 마세요. 잘못된 기존 기록을 확인한 뒤 정정하고, 직접 처리할 수 없는 결석·휴강 정정은 관리 선생님에게 요청합니다.

표시등은 미입력인데 보완할 수 있는 기록이 없어요.

표시등은 학생 전체 기간의 입력 현황입니다. 다른 선생님의 기록, 담당자를 확인할 수 없는 기록, 마감 기록이 포함될 수 있습니다. 일반 선생님은 허용된 본인 기록의 빈 수업 내용만 채울 수 있으며 실제 진행 선생님 지정은 할 수 없습니다.

보완 저장 중 화면이 오래되었거나 다른 사람이 수정했다는 안내가 나와요.

작성한 내용을 따로 보관한 뒤 최신 목록을 불러옵니다. 이미 내용이 채워졌는지, 담당·수업 정보가 바뀌었는지 확인합니다. 기존 내용을 덮어쓰려 하지 말고, 여전히 비어 있고 수정 가능한 행만 다시 확인·저장하세요.

월말보고에 기록이나 결석이 빠져 있어요.

학생, 학습 시작일·종료일, 선택 체크 상태를 확인합니다. 전체 기록 불러오기를 눌러 원본 기록이 있는지도 확인하세요. 결석은 별도로 등록된 내역만 표시되며 옛 결석을 자동으로 추정하지 않습니다. 저장한 예전 문구도 원본 변경을 자동 반영하지 않으므로 재확인해야 합니다.

월말보고 복사가 안 돼요.

브라우저의 클립보드 접근 안내를 확인하세요. 계속 실패하면 미리보기 입력칸을 클릭해 그 안의 문구만 직접 선택·복사하고 발송 도구에 붙여넣어 확인합니다. 복사나 저장만으로 실제 메시지가 발송되지는 않습니다.

정산 금액이나 차시가 예상과 달라요.
