# 일반 선생님 웹 매뉴얼 운영 안내

## 위치

- 앱 상단 `사용 매뉴얼` → 새 탭의 `/manual`
- 본문: `templates/teacher_manual.html`
- 전용 스타일: `static/css/teacher_manual.css`
- 본문 검색·목차 이동·인쇄: `static/js/teacher_manual.js`
- 경로: `main.py`의 `teacher_manual_page()`

개인정보나 계정 정보를 불러오지 않는 공개 안내 문서다. 업무 기능의 인증·권한을 변경하지 않는다. 자바스크립트가 없어도 전체 본문과 목차 링크를 읽을 수 있다. 앱 링크는 새 탭으로 열어 입력 중인 화면을 유지한다.

## 내용과 기준

빠른 시작 및 10개 장: 처음 시작하기, 수업 전 확인, 일괄 등록, 개별 등록, 기록 정정, 미입력 보완, 월말보고, 도서·자료 요청, 본인 월급 정산, 문제 해결.

화면 버튼·입력 순서는 `templates/index.html`과 `static/js/app.js`, 권한은 `main.py`, `studylog_permissions.py`, `studylog_completion.py`, `consultation_payroll.py` 및 관련 기능을 기준으로 확인한다. 일반 선생님의 본인 정산 조회는 가능하며 마감·제외·단가 설정은 권한이 다르므로 구분한다.

## 수정 원칙

1. 사용 목적 → 메뉴 경로 → 절차 → 완료 확인 → 주의사항 → 관련 도움말 순서를 유지한다.
2. 버튼·필드명은 실제 서비스의 한국어 이름을 사용한다.
3. 허용 범위와 마감 제한을 화면 및 서버 양쪽에서 확인한다.
4. 실제 학생 이름·연락처·상담 원문·계정 정보는 예문이나 화면 사진에 포함하지 않는다.
5. 장의 `id`를 유지하여 공유한 바로가기 주소가 깨지지 않게 한다.
6. 검색은 공백으로 나눈 모든 단어가 포함된 장을 표시한다. 검색 중 목차를 누르면 검색을 해제하고 해당 장으로 이동한다.
7. 전체 인쇄는 검색에 숨겨진 장도 모두 포함하며 문제 해결의 접힌 항목도 펼쳐 출력한다.
8. 기능 변경 시 문서 기준일·버전과 자산 캐시 버전을 함께 갱신한다.

## 검증

- `.venv\Scripts\python.exe -m unittest discover -s tests -p test_teacher_manual.py`
- `node --check static/js/teacher_manual.js`
- `python server_daemon.py`로 서버를 기동하고 `/manual`을 확인한다.
- 첫 화면, 검색 결과·결과 없음·검색 해제, 목차 이동, 주소 재접속, 전체 인쇄, 좁은 화면을 확인한다.
- 기존 업무 화면과 운영 DB를 테스트 입력으로 변경하지 않는다.

## 문체 기준

[im-not-ai의 humanize-korean 스킬](https://github.com/epoko77-ai/im-not-ai/blob/main/skills/humanize-korean/SKILL.md)과 윤문 처방집을 참고한다. 스킬을 설치하거나 자동 점수 검사를 실행한 것은 아니다.

- 홍보성 제목, 추상적인 격려, 반복되는 도입 설명은 줄인다.
- `~을 통해`, `~하는 기능입니다`처럼 돌아가는 표현은 실제 동작을 설명하는 문장으로 고친다.
- 버튼명·수치·처리 순서·권한·마감 제한·예외 조건은 바꾸지 않는다.
- 매뉴얼에 필요한 번호 순서, 목차, 버튼명 강조는 유지한다. 자연스럽게 보이게 하려고 일부러 말투를 섞거나 새로운 경험담을 넣지 않는다.
- 수정 전후를 대조한 뒤 웹 문서와 배포용 HTML 사본에 같은 내용을 반영한다.

## 사진 중심 매뉴얼 2.0

- `static/images/manual/`의 실제 화면 32장을 33곳에 배치한다. 학생 검색 화면은 두 업무에서 함께 사용한다.
- 빨간 번호와 바로 옆·아래 설명을 맞추고, 한 번에 선택한 업무 한 장만 펼친다. 기존 상세 설명은 `글로 된 설명·주의사항 보기`에 보존한다.
- 사진을 누르면 확대창에서 전체 보기·원본 크기를 선택할 수 있다. 검색은 접힌 설명도 포함하며, 전체 인쇄는 사진을 준비한 뒤 모든 업무를 출력한다.
- `manifest.json`에 사진 파일·크기·표시 번호를 기록한다. 화면 변경 시 사진과 설명을 함께 갱신한다.
- `tests/manual_capture_app.py`는 `MANUAL_DEMO_DIR`을 반드시 지정해야 하는 별도 촬영용 앱이다. 운영 DB를 복사하지 않고 별도 DB에 가상 학생·도서·수업을 생성하며 일반 선생님 역할로 촬영한다. 외부에 배포하지 않는다.
- 캡처용 계정·비밀번호·DB·원본 작업 파일은 저장소에 넣지 않는다. 사진에는 설명용 자료임을 명시한다.
- 2026-10-05 검증: 구조 테스트 7개, 자바스크립트 구문, 사진 확대·닫기, 검색·초기화, 번호 대조, 390×844 및 1024×600 프레임에서 가로 넘침 없음.
