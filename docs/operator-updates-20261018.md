# 관리 역할용 사용안내

## 빠른 수정

학생·도서 검색 목록에서 **빠른 수정** 스위치를 켜면 관리 역할(관리자·부관리자·관리 선생님)이 선택형 항목을 바로 바꿀 수 있습니다. 스위치는 기본으로 꺼져 있으며, 다른 화면으로 이동하면 자동으로 꺼집니다.

- **학생**: 성별, 학년, 수업 상태
- **도서**: 난이도, 분량, 독서 문제 보유 여부, PDF 상태
- 이름·도서명·설명 같은 자유 입력 항목은 목록에서 수정하지 않고 상세 화면에서 수정합니다.
- 배지를 클릭하면 다음 값으로 순환합니다. `Shift`를 누른 채 클릭하면 이전 값으로 순환합니다.
- 기존 값이 선택지에 없는 자유 입력값이면 첫 클릭 때 선택지가 열립니다. 현재 값은 선택하기 전까지 유지되며, 원하는 선택지를 눌러야 변경됩니다.
- 저장 중에는 같은 항목을 다시 저장할 수 없습니다. 저장에 실패하면 기존 값이 유지되고 다시 시도할 수 있습니다.
- 저장 성공 후 **10초 동안** `방금 변경 되돌리기 (10초)`를 사용할 수 있습니다. 되돌리기 전에 서버 값을 다시 확인하며, 다른 변경이 확인되면 되돌리지 않고 중단합니다.
- 화면을 이동하면 빠른 수정이 해제되고 선택지·되돌리기 버튼도 사라집니다. 화면 이동 자체가 저장 실패를 의미하는 것은 아니므로, 저장 완료 안내를 확인한 뒤 이동하세요.

## 결제·납입 목록의 잔여 차시 정렬

- **결제 이력 조회**의 `결제/서비스` 열은 현재 결제의 잔여 차시를 숫자로 정렬합니다.
- **납입 관리**의 잔여 차시도 숫자로 정렬합니다. 초과 사용은 음수로 비교하고, 소진은 0으로 처리합니다.
- 결제 정보 없음, 학생 정보 확인 필요, 과거·시작 예정 등 숫자로 비교할 수 없는 값은 오름차순과 내림차순 모두 목록 뒤에 배치됩니다.
- 정렬은 현재 페이지 안에서 적용됩니다. 서버가 정한 기본 긴급도나 검색 결과 자체를 바꾸는 기능은 아닙니다.

## 조회 목록 순서 유지

상세 수정 후 목록을 다시 불러올 때, 화면에 표시 중이던 행은 안정적인 식별자를 기준으로 기존 상대 순서를 유지합니다. 조건에서 빠진 행은 제거되고 새로 나타난 행은 뒤에 붙습니다. 로딩·오류 안내 행이 기존 순서를 덮어쓰지는 않습니다.

다음 경우에는 새 결과 집합으로 취급하므로 기존 순서를 유지하지 않습니다.

- 검색 조건, 필터, 페이지를 변경한 경우
- 열 정렬을 직접 변경한 경우
- 서버 정렬을 다시 요청하는 화면 또는 서버 페이지가 바뀐 경우

따라서 이 기능은 전체 검색 결과의 고정 순서를 보장하거나, 다른 페이지의 행 순서까지 기억하는 기능이 아닙니다.

## Esc로 대화상자 닫기

`Esc`를 누르면 화면 맨 위의 닫을 수 있는 대화상자 하나만 닫습니다. 저장 중인 작업, 저장하지 않은 입력 확인, 필수 로그인 창의 보호를 우회하지 않습니다.

- 입력 중인 납입 관리 창은 저장하지 않은 내용을 버릴지 먼저 확인합니다.
- 보완 저장 중에는 닫기 동작이 막힙니다.
- `Esc`를 길게 눌러 뒤쪽 대화상자까지 연속으로 닫을 수 없습니다.
- 한글 조합 중 `Esc`는 대화상자 닫기로 처리하지 않습니다.
