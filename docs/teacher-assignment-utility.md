# 기존 학습 기록 선생님 지정

운영 배포 후 관리 선생님 이상 계정으로 **유틸리티 → 기존 학습 기록 선생님 지정**에서 실행합니다.

1. Google Sheets의 선생님별 차시표를 XLSX 또는 CSV로 내려받습니다.
2. 파일과 운영에 등록된 실제 진행 선생님을 선택합니다.
3. 필요하면 대상 월을 지정하고 **지정 대상 미리보기**를 누릅니다.
4. 학생·실제 학습일·기존 도서·판정 사유를 확인하고 적용할 항목을 선택합니다.
5. **선택 항목 적용**을 누릅니다. 변경 내용은 기존 변경 이력 조회에 남습니다.

미리보기의 **CSV 내보내기** 버튼으로 제외 항목까지 전체 결과를 내려받을 수 있습니다. 파일에는 원본 파일명, 대상 선생님, 대상 월, 행별 선택 여부·학생·실제 학습일·도서·현재 선생님·판정 사유가 포함됩니다. 적용용 인증 정보는 포함하지 않습니다. CSV 내보내기는 학습 기록을 변경하지 않습니다.

XLSX는 모든 시트를 읽습니다. `이름, 1차시, 2차시, …` 또는 `이름, 일자` 헤더를 지원합니다. 파일은 5MB, 한 번에 처리할 차시는 3,000건까지입니다.

날짜는 셀 값을 우선합니다. 예를 들어 `2026-7월` 탭의 `2026-06-13`은 6월 13일 기록에 대응합니다. 대상 월을 6월로 설정해도 해당 항목이 포함됩니다. `6/13`처럼 연도가 없으면 시트명·파일명의 연도를 사용하고, 그것도 없으면 대상 월의 연도를 사용합니다. 대상 월을 비우면 전체 기간을 대조합니다.

학생 이름은 파일과 서버 양쪽의 괄호 내용(중첩·전각 괄호 포함)을 제외하고 대조합니다. 서버 원본 이름과 학생 ID는 그대로 보존하며 미리보기와 CSV에 표시합니다. 괄호를 제외해 동명이인이 생기면 서버 학생별 후보를 보여 주고 자동 선택하지 않습니다.

같은 날짜에 여러 도서가 있으면 서버 학습 기록 ID별로 표시하며 각각 선택할 수 있습니다. 여러 후보는 자동 선택하지 않으므로 학생명·학생 ID·도서·학습 기록 ID를 확인해 선택해야 합니다. 파일에 같은 날짜가 여러 번 나와도 서로 다른 기록 ID는 별도로 유지합니다. 동일한 서버 기록 ID가 반복될 때만 중복으로 표시하고 최초 항목에서 한 번만 선택합니다.

미등록 학생, 미등록 학습일, 이미 지정된 선생님, 연결 수업의 다른 담당자, 정산 마감 항목은 적용에서 제외됩니다.

이 기능은 `ActualTeacherUsername`과 수정자·수정 시각만 변경합니다. 신규 기록 생성, 수업 연결, 정산 카테고리 지정은 하지 않습니다. 이미 수업·카테고리에 연결된 기록은 교사 지정에 따라 기존 정산 계산에 반영될 수 있습니다. 적용 시 현재 상태를 다시 확인하며, 충돌이나 감사 기록 오류가 생기면 선택한 항목 전체를 취소합니다. 미리보기 유효 시간은 30분입니다.

## 배포 및 검증

`requirements.txt`에 XLSX 읽기용 `openpyxl==3.1.5`를 추가했습니다. 해당 모듈이 없는 운영 환경에서도 파이썬 기본 라이브러리로 차시표의 저장된 셀 값을 읽습니다. 코드 배포 후 서버를 재시작해야 합니다. 업로드 파일은 영구 보관하지 않습니다.

회귀 검증은 임시 SQLite를 만들고 삭제하며 실제 DB를 사용하지 않습니다.

```powershell
python -m unittest discover -s tests -p test_teacher_assignment.py -v
```

테스트에는 설치된 Starlette의 TestClient가 요구하는 HTTP 클라이언트(`httpx` 또는 `httpx2`)가 필요합니다. 이는 운영 기능의 의존성은 아닙니다.
