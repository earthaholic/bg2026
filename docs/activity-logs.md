# 사용자 활동 이력

## 변경 이력과 구분

- 기존 `_app_audit_logs`와 변경 이력 조회 UI/API/권한을 유지한다. 관리 선생님(manager)도 기존처럼 변경 이력을 조회할 수 있다.
- `_app_activity_logs`는 로그인, 화면 진입, 조회, 검색, 내보내기, 업무 요청의 결과를 별도로 기록한다. 조회 권한은 admin/subadmin만 갖는다.
- 활동 건수는 HTTP 요청 단위이며 기여량이 아니다. 일괄 등록도 활동에서는 요청 한 건이고, 변경 이력에서는 기존 방식으로 각 레코드를 기록한다.
- 기존 변경 이력의 수정 집계 방식도 바꾸지 않는다. 변경 이력 상세 연결이나 기여량 집계 개편은 이번 구현에 포함하지 않는다.

## 사용 방법

관리 도구 → **사용자 활동 이력**에서 계정, 시작일·종료일, 활동, 업무 영역, 결과를 선택한다. 기본 조회 기간은 오늘을 포함한 최근 7일이다.

요약은 선택한 모든 필터를 적용한 활동 건수·계정 수·로그인 성공·실패 건수이다. 페이지당 30건을 최신 순으로 표시하며, 상세 버튼으로 요청 ID, 처리 시간, 세션 ID, 필터 종류를 확인한다. 날짜와 시각은 한국 시간이다.

로그인 실패의 입력 계정은 실제 행위자가 아니므로 `로그인 시도`로 표시한다. 해당 기록은 실패 필터와 전체 계정으로 확인한다. 인증된 계정 필터는 로그인 실패의 시도 계정을 포함하지 않는다.

## 수집 범위

- 서버: 로그인 성공·실패, 명시적 로그아웃, 주요 API 목록·상세 조회, 등록·수정·삭제 요청, CSV 가져오기·내보내기, SQL 실행, 이력 조회, 실패 응답.
- 프론트엔드: 허용된 메뉴 진입. 클라이언트 보고임을 표시하며 서버에서 검증한 사용자와 연결한다.
- 도서·학생·학습기록·수업 검색 버튼 및 도서·학생·수업의 Enter 검색은 `직접 검색`으로 구분한다. 초기 로딩, 페이지 이동, 필터 자동 갱신 등은 `목록 조회`이다. 검색 의도는 클라이언트가 표시하므로 보안 증거로 사용하지 않는다.
- 최근 항목, 자동완성, 선택 옵션, 인증 상태 확인 등 보조 GET 요청은 성공 시 제외한다. 실패는 기록한다.
- 결과는 HTTP 응답 상태를 기준으로 한다. 화면 진입은 보고 요청의 접수를 뜻하며, 응답이 성공해도 사용자가 내용을 읽었다거나 파일을 저장했다는 증거는 아니다.
- 경로상의 대상 ID만 저장한다. 생성 요청의 새 ID나 결과 건수·본문은 수집하지 않는다. 상세 요청 경로는 실제 입력 경로 대신 `/api/user/books/{book_id}` 같은 라우트 템플릿을 저장한다.

## 저장과 운영

`activity.py`의 라우터·미들웨어를 `main.py`에서 등록한다. 시작 시 테이블과 인덱스를 생성한다. 기존 도메인·변경 이력 데이터는 마이그레이션하지 않는다. `_app_` 테이블은 기존 Studio 목록 및 Oracle 동기화 DROP 대상에서 제외된다.

- UTC 저장, 한국 시간 날짜 필터. 한 번에 최대 180일 조회.
- 활동 보관 기간 180일. 기록할 때 만료된 행을 최대 100건씩 정리한다. 사용이 없으면 정리도 실행되지 않으며 백업 파일은 이 정리 대상이 아니다.
- 비밀번호·JWT·검색어 값·SQL 원문·요청/응답 본문·IP는 저장하지 않는다. 검색 필터는 허용된 키 이름만 저장한다.
- 신규 로그인마다 임의의 세션 ID를 JWT에 부여한다. 기존 JWT도 계속 동작하지만 재로그인 전까지 세션 ID는 없다. 로그아웃 기록은 기존 JWT를 서버에서 폐기하는 기능을 추가하지 않는다.
- 기록 쓰기는 별도 DB 연결과 스레드에서 실행하고, 잠금 대기는 250ms로 제한한다. 실패해도 원래 응답은 유지하고 `logs/uvicorn.log`에 요청 ID와 오류를 남긴다. 기록 전달을 보장하는 재시도 큐는 없다.
- 로그 수정·삭제 API는 제공하지 않는다. 다만 DB 파일이나 관리자 SQL 권한 보유자에 대한 위변조 방지는 제공하지 않는다.

## 검증

복사한 임시 DB에서 4개 역할의 접근 제어, 기존 manager 변경 이력 조회, 활동과 변경 이력의 건수 분리, 도서 등록·수정·삭제, 검색 의도 구분, 로그인 실패 식별, 세션 연결, SQL·CSV 요청, 필터·기간·페이지, 민감정보 미저장을 검증한다. 브라우저에서는 실제 관리자 메뉴·목록·필터·상세를 확인한다.
